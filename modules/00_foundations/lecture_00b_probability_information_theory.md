## 1. Motivation

Deep learning is fundamentally a probabilistic endeavor:
- **Training** minimizes cross-entropy loss, which is the negative log-likelihood under the model distribution — an information-theoretic quantity.
- **Generative models** (VAEs, diffusion models, normalizing flows) explicitly model $p(\mathbf{x})$ or learn to sample from it.
- **Regularization** corresponds to placing priors on parameters (L2 = Gaussian prior, L1 = Laplace prior).
- **Dropout** is equivalent to approximate Bayesian inference over network weights.
- **The reparameterization trick** in VAEs requires understanding of change of variables for random variables.
- **KL divergence** appears in the ELBO, in DPO objectives, and in knowledge distillation.

A working mastery of probability and information theory is essential for understanding not just *what* deep learning methods do, but *why* they are designed the way they are.

## 2. Core Theory

### 2.1 Probability Spaces

**Definition (Probability space).** A probability space is a triple $(\Omega, \mathcal{F}, P)$ where:
- $\Omega$ is the *sample space* (set of all possible outcomes).
- $\mathcal{F}$ is a *sigma-algebra* on $\Omega$ (a collection of subsets closed under complementation and countable unions, containing $\Omega$).
- $P : \mathcal{F} \to [0, 1]$ is a *probability measure* satisfying $P(\Omega) = 1$ and countable additivity.

For deep learning purposes, we typically work in $\Omega = \mathbb{R}^d$ with the Borel sigma-algebra (generated by open sets).

**Why this matters:** When we write $p(\mathbf{x})$ for a continuous distribution, $p$ is a density function, *not* a probability. The probability of a set $A$ is $P(A) = \int_A p(\mathbf{x})\,d\mathbf{x}$. The distinction matters when performing change of variables (e.g., in normalizing flows).

### 2.2 Random Variables

**Definition.** A *random variable* is a measurable function $X : \Omega \to \mathbb{R}$ (or $\mathbb{R}^d$ for random vectors). A random variable is characterized by its *cumulative distribution function* (CDF):

$$F_X(x) = P(X \le x) = P(\{\omega \in \Omega : X(\omega) \le x\})$$

**Discrete random variables** have a *probability mass function* (PMF): $p(x) = P(X = x)$.

**Continuous random variables** have a *probability density function* (PDF): $p(x) = F_X'(x)$, so that $P(a \le X \le b) = \int_a^b p(x)\,dx$.

### 2.3 Common Distributions

#### Bernoulli Distribution

$X \sim \text{Ber}(p)$ where $p \in [0, 1]$:

$$P(X = 1) = p, \quad P(X = 0) = 1 - p$$
$$\mathbb{E}[X] = p, \quad \text{Var}(X) = p(1-p)$$

**DL connection:** Binary classification outputs a Bernoulli parameter via sigmoid: $\hat{p} = \sigma(\mathbf{w}^\top \mathbf{x} + b)$.

#### Categorical Distribution

$X \sim \text{Cat}(\boldsymbol{\pi})$ where $\boldsymbol{\pi} \in \Delta^K$ (the probability simplex):

$$P(X = k) = \pi_k, \quad k \in \{1, \dots, K\}, \quad \sum_{k=1}^K \pi_k = 1$$

**DL connection:** Multi-class classification outputs categorical parameters via softmax: $\hat{\pi}_k = \text{softmax}(\mathbf{z})_k = e^{z_k} / \sum_j e^{z_j}$.

#### Gaussian (Normal) Distribution

**Univariate:** $X \sim \mathcal{N}(\mu, \sigma^2)$:

$$p(x) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\!\left(-\frac{(x - \mu)^2}{2\sigma^2}\right)$$

$$\mathbb{E}[X] = \mu, \quad \text{Var}(X) = \sigma^2$$

**Multivariate:** $\mathbf{x} \sim \mathcal{N}(\boldsymbol{\mu}, \Sigma)$ where $\boldsymbol{\mu} \in \mathbb{R}^d$, $\Sigma \in \mathbb{R}^{d \times d}$ is symmetric positive definite:

$$p(\mathbf{x}) = \frac{1}{(2\pi)^{d/2} |\Sigma|^{1/2}} \exp\!\left(-\frac{1}{2}(\mathbf{x} - \boldsymbol{\mu})^\top \Sigma^{-1} (\mathbf{x} - \boldsymbol{\mu})\right)$$

**Key properties:**
- The Gaussian is closed under affine transformations: if $\mathbf{x} \sim \mathcal{N}(\boldsymbol{\mu}, \Sigma)$, then $A\mathbf{x} + \mathbf{b} \sim \mathcal{N}(A\boldsymbol{\mu} + \mathbf{b}, A\Sigma A^\top)$.
- Marginals and conditionals of a joint Gaussian are also Gaussian.
- The Gaussian maximizes entropy for a given mean and covariance (proved in Section 3.3).

**DL connection:** Gaussian distributions appear everywhere — weight initialization, latent spaces in VAEs, noise in diffusion models, the reparameterization trick $\mathbf{z} = \boldsymbol{\mu} + \Sigma^{1/2}\boldsymbol{\epsilon}$ where $\boldsymbol{\epsilon} \sim \mathcal{N}(\mathbf{0}, I)$.

### 2.4 Expectations and Moments

**Definition.** The *expectation* of a function $g(X)$ under distribution $p$ is:

$$\mathbb{E}_p[g(X)] = \int g(x)\,p(x)\,dx \quad \text{(continuous)}$$
$$\mathbb{E}_p[g(X)] = \sum_x g(x)\,p(x) \quad \text{(discrete)}$$

**Key properties (linearity):**
- $\mathbb{E}[\alpha X + \beta Y] = \alpha\,\mathbb{E}[X] + \beta\,\mathbb{E}[Y]$ (always, even if $X$ and $Y$ are dependent)
- $\mathbb{E}[XY] = \mathbb{E}[X]\,\mathbb{E}[Y]$ only if $X$ and $Y$ are independent.

**Moments:**
- *Mean*: $\mu = \mathbb{E}[X]$ (first moment)
- *Variance*: $\text{Var}(X) = \mathbb{E}[(X - \mu)^2] = \mathbb{E}[X^2] - (\mathbb{E}[X])^2$ (second central moment)
- *Covariance*: $\text{Cov}(X, Y) = \mathbb{E}[(X - \mathbb{E}[X])(Y - \mathbb{E}[Y])]$
- *Covariance matrix*: $\Sigma = \mathbb{E}[(\mathbf{x} - \boldsymbol{\mu})(\mathbf{x} - \boldsymbol{\mu})^\top]$, $\Sigma_{ij} = \text{Cov}(X_i, X_j)$

**Law of the Unconscious Statistician (LOTUS):** If $Y = g(X)$ and we know $p_X$, then $\mathbb{E}[Y] = \int g(x)\,p_X(x)\,dx$ — we do not need $p_Y$ explicitly.

### 2.5 Joint, Conditional, and Marginal Distributions

**Joint distribution:** $p(\mathbf{x}, \mathbf{y})$ describes the probability over pairs $(\mathbf{x}, \mathbf{y})$.

**Marginal distribution:** $p(\mathbf{x}) = \int p(\mathbf{x}, \mathbf{y})\,d\mathbf{y}$ (integrating/summing out the other variable).

**Conditional distribution:** $p(\mathbf{y} | \mathbf{x}) = p(\mathbf{x}, \mathbf{y}) / p(\mathbf{x})$, defined when $p(\mathbf{x}) > 0$.

**Product rule:** $p(\mathbf{x}, \mathbf{y}) = p(\mathbf{y} | \mathbf{x})\,p(\mathbf{x}) = p(\mathbf{x} | \mathbf{y})\,p(\mathbf{y})$.

**Independence:** $\mathbf{x} \perp\!\!\!\perp \mathbf{y}$ iff $p(\mathbf{x}, \mathbf{y}) = p(\mathbf{x})\,p(\mathbf{y})$, equivalently $p(\mathbf{y} | \mathbf{x}) = p(\mathbf{y})$.

**Conditional independence:** $\mathbf{x} \perp\!\!\!\perp \mathbf{y} \mid \mathbf{z}$ iff $p(\mathbf{x}, \mathbf{y} | \mathbf{z}) = p(\mathbf{x} | \mathbf{z})\,p(\mathbf{y} | \mathbf{z})$.

**Law of total expectation:** $\mathbb{E}[Y] = \mathbb{E}_X[\mathbb{E}[Y | X]]$.

**Law of total variance:** $\text{Var}(Y) = \mathbb{E}_X[\text{Var}(Y | X)] + \text{Var}_X(\mathbb{E}[Y | X])$.

### 2.6 Bayes' Theorem

**Theorem (Bayes).** For events $A$ and $B$ with $P(B) > 0$:

$$P(A | B) = \frac{P(B | A)\,P(A)}{P(B)}$$

For continuous densities with parameter $\theta$ and data $\mathcal{D}$:

$$\underbrace{p(\theta | \mathcal{D})}_{\text{posterior}} = \frac{\overbrace{p(\mathcal{D} | \theta)}^{\text{likelihood}} \cdot \overbrace{p(\theta)}^{\text{prior}}}{\underbrace{p(\mathcal{D})}_{\text{evidence}}}$$

where $p(\mathcal{D}) = \int p(\mathcal{D} | \theta)\,p(\theta)\,d\theta$ is the *marginal likelihood* or *evidence*.

**Maximum likelihood estimation (MLE):** Ignores the prior; finds $\hat{\theta}_{\text{MLE}} = \arg\max_\theta p(\mathcal{D} | \theta)$.

**Maximum a posteriori (MAP):** Finds $\hat{\theta}_{\text{MAP}} = \arg\max_\theta p(\theta | \mathcal{D}) = \arg\max_\theta \bigl[\log p(\mathcal{D} | \theta) + \log p(\theta)\bigr]$.

**DL connection:** MAP with a Gaussian prior $p(\theta) = \mathcal{N}(\mathbf{0}, (1/\lambda)I)$ corresponds to L2 regularization (weight decay) with coefficient $\lambda$.

### 2.7 Conjugate Priors

**Definition.** A prior $p(\theta)$ is *conjugate* to a likelihood $p(\mathcal{D} | \theta)$ if the posterior $p(\theta | \mathcal{D})$ belongs to the same family as the prior.

**Key conjugate pairs:**

| Likelihood | Conjugate Prior | Posterior |
|-----------|----------------|-----------|
| Bernoulli | Beta($\alpha$, $\beta$) | Beta($\alpha + k$, $\beta + n - k$) |
| Categorical | Dirichlet($\boldsymbol{\alpha}$) | Dirichlet($\boldsymbol{\alpha} + \mathbf{c}$) |
| Gaussian (known $\sigma^2$) | Gaussian | Gaussian |
| Gaussian (known $\mu$) | Inverse-Gamma | Inverse-Gamma |

**Example: Beta-Bernoulli model.** Prior: $\theta \sim \text{Beta}(\alpha, \beta)$. Observe $k$ successes in $n$ trials. Posterior:

$$\theta | \text{data} \sim \text{Beta}(\alpha + k, \beta + n - k)$$

Posterior mean: $\mathbb{E}[\theta | \text{data}] = (\alpha + k) / (\alpha + \beta + n)$. As $n \to \infty$, this converges to $k/n$ (the MLE), showing the prior is "washed out" by data.

## 3. Information Theory

### 3.1 Entropy

**Definition.** The *(Shannon) entropy* of a discrete random variable $X$ with PMF $p$ is:

$$H(p) = -\sum_{x} p(x) \log p(x) = \mathbb{E}_p[-\log p(X)]$$

For continuous random variables, the *differential entropy* is:

$$h(p) = -\int p(x) \log p(x)\,dx$$

**Interpretation:** $H(p)$ measures the average number of bits (if $\log$ is base 2) or nats (if $\log$ is natural) needed to encode a sample from $p$.

**Properties:**
- $H(p) \ge 0$ for discrete distributions (equality iff $p$ is a point mass).
- $H(p) \le \log |\mathcal{X}|$ where $|\mathcal{X}|$ is the number of outcomes (maximized by the uniform distribution).
- Differential entropy can be negative (e.g., for a very peaked continuous distribution).

### 3.2 Cross-Entropy

**Definition.** The cross-entropy between distributions $p$ and $q$ is:

$$H(p, q) = -\mathbb{E}_p[\log q(X)] = -\sum_x p(x) \log q(x)$$

**Relationship to entropy and KL divergence:**

$$H(p, q) = H(p) + \text{KL}(p \| q)$$

**DL connection:** Training a classifier to minimize cross-entropy loss is equivalent to minimizing the KL divergence between the true label distribution and the model's predicted distribution, since $H(p)$ is constant with respect to model parameters.

Specifically, for a dataset $\{(\mathbf{x}_i, y_i)\}_{i=1}^N$ with one-hot labels, the cross-entropy loss is:

$$\mathcal{L} = -\frac{1}{N}\sum_{i=1}^N \log q(y_i | \mathbf{x}_i; \theta) = -\frac{1}{N}\sum_{i=1}^N \log \frac{\exp(z_{y_i})}{\sum_k \exp(z_k)}$$

where $z_k$ are the logits.

### 3.3 KL Divergence

**Definition.** The Kullback-Leibler divergence from $q$ to $p$ is:

$$\text{KL}(p \| q) = \mathbb{E}_p\!\left[\log \frac{p(X)}{q(X)}\right] = \sum_x p(x) \log \frac{p(x)}{q(x)}$$

**Theorem (Non-negativity of KL divergence / Gibbs' inequality).** For any distributions $p$ and $q$:

$$\text{KL}(p \| q) \ge 0$$

with equality if and only if $p = q$ (a.e.).

*Proof via Jensen's inequality.* Since $-\log$ is a strictly convex function and Jensen's inequality states $\mathbb{E}[g(X)] \ge g(\mathbb{E}[X])$ for convex $g$:

$$\text{KL}(p \| q) = \mathbb{E}_p\!\left[-\log \frac{q(X)}{p(X)}\right] \ge -\log \mathbb{E}_p\!\left[\frac{q(X)}{p(X)}\right]$$

Now evaluate the expectation:

$$\mathbb{E}_p\!\left[\frac{q(X)}{p(X)}\right] = \sum_x p(x) \cdot \frac{q(x)}{p(x)} = \sum_x q(x) = 1$$

Therefore:

$$\text{KL}(p \| q) \ge -\log 1 = 0$$

Equality holds iff $q(x)/p(x)$ is constant a.e. under $p$, which (together with both summing to 1) implies $p = q$. $\square$

**Corollary (Gibbs' inequality restated).** $H(p, q) \ge H(p)$ for all $q$, with equality iff $q = p$. This means: to encode samples from $p$, using $p$ itself as the codebook is optimal. Any other distribution $q$ incurs extra cost equal to $\text{KL}(p \| q)$.

**Important property: asymmetry.** $\text{KL}(p \| q) \ne \text{KL}(q \| p)$ in general. The choice matters:
- *Forward KL* $\text{KL}(p \| q)$: mode-covering; $q$ spreads to cover all of $p$'s mass.
- *Reverse KL* $\text{KL}(q \| p)$: mode-seeking; $q$ concentrates on one mode of $p$.

In VAEs, the ELBO involves $\text{KL}(q_\phi(\mathbf{z} | \mathbf{x}) \| p(\mathbf{z}))$ — the reverse KL from approximate posterior to prior.

### 3.4 KL Divergence Between Two Gaussians

**Proposition.** Let $p = \mathcal{N}(\boldsymbol{\mu}_1, \Sigma_1)$ and $q = \mathcal{N}(\boldsymbol{\mu}_2, \Sigma_2)$ be $d$-dimensional Gaussians. Then:

$$\text{KL}(p \| q) = \frac{1}{2}\left[\text{tr}(\Sigma_2^{-1}\Sigma_1) + (\boldsymbol{\mu}_2 - \boldsymbol{\mu}_1)^\top \Sigma_2^{-1}(\boldsymbol{\mu}_2 - \boldsymbol{\mu}_1) - d + \log\frac{|\Sigma_2|}{|\Sigma_1|}\right]$$

*Derivation.* We compute $\text{KL}(p \| q) = \mathbb{E}_p[\log p(\mathbf{x})] - \mathbb{E}_p[\log q(\mathbf{x})]$ term by term.

First: $\mathbb{E}_p[\log p(\mathbf{x})] = -\frac{d}{2}\log(2\pi) - \frac{1}{2}\log|\Sigma_1| - \frac{1}{2}\mathbb{E}_p[(\mathbf{x}-\boldsymbol{\mu}_1)^\top\Sigma_1^{-1}(\mathbf{x}-\boldsymbol{\mu}_1)]$

The quadratic form expectation: $\mathbb{E}_p[(\mathbf{x}-\boldsymbol{\mu}_1)^\top\Sigma_1^{-1}(\mathbf{x}-\boldsymbol{\mu}_1)] = \text{tr}(\Sigma_1^{-1}\Sigma_1) = d$.

So: $\mathbb{E}_p[\log p(\mathbf{x})] = -\frac{d}{2}\log(2\pi) - \frac{1}{2}\log|\Sigma_1| - \frac{d}{2}$

Second: $\mathbb{E}_p[\log q(\mathbf{x})] = -\frac{d}{2}\log(2\pi) - \frac{1}{2}\log|\Sigma_2| - \frac{1}{2}\mathbb{E}_p[(\mathbf{x}-\boldsymbol{\mu}_2)^\top\Sigma_2^{-1}(\mathbf{x}-\boldsymbol{\mu}_2)]$

Expand the quadratic form by substituting $\mathbf{x} - \boldsymbol{\mu}_2 = (\mathbf{x} - \boldsymbol{\mu}_1) + (\boldsymbol{\mu}_1 - \boldsymbol{\mu}_2)$:

$$\mathbb{E}_p[(\mathbf{x}-\boldsymbol{\mu}_2)^\top\Sigma_2^{-1}(\mathbf{x}-\boldsymbol{\mu}_2)] = \text{tr}(\Sigma_2^{-1}\Sigma_1) + (\boldsymbol{\mu}_1 - \boldsymbol{\mu}_2)^\top\Sigma_2^{-1}(\boldsymbol{\mu}_1 - \boldsymbol{\mu}_2)$$

(The cross terms vanish because $\mathbb{E}_p[\mathbf{x} - \boldsymbol{\mu}_1] = \mathbf{0}$.)

Combining:

$$\text{KL}(p\|q) = \frac{1}{2}\left[\log\frac{|\Sigma_2|}{|\Sigma_1|} - d + \text{tr}(\Sigma_2^{-1}\Sigma_1) + (\boldsymbol{\mu}_1 - \boldsymbol{\mu}_2)^\top\Sigma_2^{-1}(\boldsymbol{\mu}_1 - \boldsymbol{\mu}_2)\right] \quad \square$$

**Special case (VAE KL term).** When $p = \mathcal{N}(\boldsymbol{\mu}, \text{diag}(\boldsymbol{\sigma}^2))$ and $q = \mathcal{N}(\mathbf{0}, I)$:

$$\text{KL}(p \| q) = \frac{1}{2}\sum_{j=1}^d \left[\sigma_j^2 + \mu_j^2 - 1 - \log\sigma_j^2\right]$$

This is the closed-form KL term in the VAE ELBO.

### 3.5 Entropy of the Multivariate Gaussian

**Proposition.** If $\mathbf{x} \sim \mathcal{N}(\boldsymbol{\mu}, \Sigma)$, then:

$$h(\mathbf{x}) = \frac{d}{2}\log(2\pi e) + \frac{1}{2}\log|\Sigma| = \frac{1}{2}\log\bigl((2\pi e)^d |\Sigma|\bigr)$$

*Derivation.*

$$h(\mathbf{x}) = -\mathbb{E}\!\left[\log p(\mathbf{x})\right] = -\mathbb{E}\!\left[-\frac{d}{2}\log(2\pi) - \frac{1}{2}\log|\Sigma| - \frac{1}{2}(\mathbf{x}-\boldsymbol{\mu})^\top\Sigma^{-1}(\mathbf{x}-\boldsymbol{\mu})\right]$$

$$= \frac{d}{2}\log(2\pi) + \frac{1}{2}\log|\Sigma| + \frac{1}{2}\mathbb{E}\!\left[(\mathbf{x}-\boldsymbol{\mu})^\top\Sigma^{-1}(\mathbf{x}-\boldsymbol{\mu})\right]$$

The expectation of the quadratic form:

$$\mathbb{E}\!\left[(\mathbf{x}-\boldsymbol{\mu})^\top\Sigma^{-1}(\mathbf{x}-\boldsymbol{\mu})\right] = \text{tr}\!\left(\Sigma^{-1}\,\mathbb{E}[(\mathbf{x}-\boldsymbol{\mu})(\mathbf{x}-\boldsymbol{\mu})^\top]\right) = \text{tr}(\Sigma^{-1}\Sigma) = \text{tr}(I_d) = d$$

Therefore:

$$h(\mathbf{x}) = \frac{d}{2}\log(2\pi) + \frac{1}{2}\log|\Sigma| + \frac{d}{2} = \frac{d}{2}\log(2\pi e) + \frac{1}{2}\log|\Sigma| \quad \square$$

### 3.6 Maximum Entropy Distributions

**Theorem.** Among all distributions on $\mathbb{R}^d$ with mean $\boldsymbol{\mu}$ and covariance $\Sigma$, the multivariate Gaussian $\mathcal{N}(\boldsymbol{\mu}, \Sigma)$ has maximum differential entropy.

*Proof sketch.* Let $p$ be any distribution with mean $\boldsymbol{\mu}$ and covariance $\Sigma$, and let $q = \mathcal{N}(\boldsymbol{\mu}, \Sigma)$. By non-negativity of KL divergence:

$$0 \le \text{KL}(p \| q) = \mathbb{E}_p[\log p(\mathbf{x})] - \mathbb{E}_p[\log q(\mathbf{x})] = -h(p) - \mathbb{E}_p[\log q(\mathbf{x})]$$

Now compute $\mathbb{E}_p[\log q(\mathbf{x})]$. Since $q$ is Gaussian:

$$\mathbb{E}_p[\log q(\mathbf{x})] = -\frac{d}{2}\log(2\pi) - \frac{1}{2}\log|\Sigma| - \frac{1}{2}\mathbb{E}_p[(\mathbf{x}-\boldsymbol{\mu})^\top\Sigma^{-1}(\mathbf{x}-\boldsymbol{\mu})]$$

The quadratic form depends only on the mean and covariance of $p$, which match those of $q$ by assumption. Therefore $\mathbb{E}_p[\log q(\mathbf{x})] = \mathbb{E}_q[\log q(\mathbf{x})] = -h(q)$.

Substituting: $0 \le -h(p) + h(q)$, i.e., $h(p) \le h(q)$. $\square$

This result justifies the use of Gaussian assumptions throughout deep learning: when all you know is the first two moments, the Gaussian is the least informative (maximum entropy) choice.

### 3.7 Mutual Information

**Definition.** The mutual information between random variables $X$ and $Y$ is:

$$I(X; Y) = \text{KL}\bigl(p(X, Y) \,\|\, p(X)\,p(Y)\bigr) = \mathbb{E}_{p(X,Y)}\!\left[\log\frac{p(X, Y)}{p(X)\,p(Y)}\right]$$

**Equivalent forms:**
$$I(X; Y) = H(X) - H(X|Y) = H(Y) - H(Y|X) = H(X) + H(Y) - H(X, Y)$$

**Properties:**
- $I(X; Y) \ge 0$ (since KL divergence is non-negative).
- $I(X; Y) = 0$ iff $X \perp\!\!\!\perp Y$.
- $I(X; Y) = I(Y; X)$ (symmetric, unlike KL divergence).

**Data Processing Inequality.** If $X \to Y \to Z$ forms a Markov chain (i.e., $Z \perp\!\!\!\perp X | Y$), then:

$$I(X; Z) \le I(X; Y)$$

*Proof.* By the chain rule for mutual information:

$$I(X; Y, Z) = I(X; Z) + I(X; Y | Z) = I(X; Y) + I(X; Z | Y)$$

Since $X \to Y \to Z$ is Markov, $I(X; Z | Y) = 0$. Also $I(X; Y | Z) \ge 0$. Therefore:

$$I(X; Z) \le I(X; Z) + I(X; Y | Z) = I(X; Y) + 0 = I(X; Y) \quad \square$$

**DL connection (Information Bottleneck).** A neural network maps input $X$ to representation $\mathbf{h}$ to output $Y$. The data processing inequality says $I(X; Y) \ge I(\mathbf{h}; Y)$ — the network cannot create information about $Y$ that is not in $X$. The *information bottleneck* principle (Tishby et al., 2000) proposes learning representations that maximize $I(\mathbf{h}; Y)$ while minimizing $I(\mathbf{h}; X)$, keeping only the task-relevant information.

### 3.8 Fisher Information

**Definition.** For a parametric family $\{p(\mathbf{x}; \theta)\}_\theta$, the *Fisher information matrix* is:

$$\mathcal{I}(\theta)_{ij} = \mathbb{E}_{p(\mathbf{x};\theta)}\!\left[\frac{\partial \log p(\mathbf{x};\theta)}{\partial \theta_i} \cdot \frac{\partial \log p(\mathbf{x};\theta)}{\partial \theta_j}\right]$$

Under regularity conditions (interchange of differentiation and integration):

$$\mathcal{I}(\theta) = -\mathbb{E}_{p(\mathbf{x};\theta)}\!\left[\frac{\partial^2 \log p(\mathbf{x};\theta)}{\partial \theta_i \,\partial \theta_j}\right]$$

**Cramer-Rao bound:** For any unbiased estimator $\hat{\theta}$ of $\theta$: $\text{Var}(\hat{\theta}) \ge \mathcal{I}(\theta)^{-1}$.

**DL connection:**
- The Fisher information matrix is the expected Hessian of the negative log-likelihood. It defines the *natural gradient*: $\tilde{\nabla} L(\theta) = \mathcal{I}(\theta)^{-1} \nabla L(\theta)$, which accounts for the geometry of the parameter space.
- *Elastic Weight Consolidation* (EWC) for continual learning penalizes deviations from old parameters weighted by the Fisher information: $\mathcal{L}_{\text{EWC}} = \mathcal{L}(\theta) + \frac{\lambda}{2}\sum_i \mathcal{I}_i(\theta^* - \theta_i)^2$.
- K-FAC (Kronecker-factored approximate curvature) approximates the Fisher for efficient second-order optimization.

## 4. Key Results: Detailed Proofs and Derivations

### 4.1 Cross-Entropy Minimization is KL Minimization

**Claim.** Minimizing $H(p, q_\theta)$ over $\theta$ is equivalent to minimizing $\text{KL}(p \| q_\theta)$.

*Proof.*

$$\text{KL}(p \| q_\theta) = H(p, q_\theta) - H(p)$$

Since $H(p)$ does not depend on $\theta$:

$$\arg\min_\theta \text{KL}(p \| q_\theta) = \arg\min_\theta H(p, q_\theta) \quad \square$$

Furthermore, if $q_\theta$ is expressive enough to represent $p$, the minimum is achieved when $q_\theta = p$, giving $\text{KL}(p \| q_\theta) = 0$ and $H(p, q_\theta) = H(p)$.

**DL implication:** When training a classifier by minimizing cross-entropy, we are fitting the model distribution $q_\theta(\mathbf{y} | \mathbf{x})$ to the true conditional distribution $p(\mathbf{y} | \mathbf{x})$ in KL divergence. This is the same as maximum likelihood estimation:

$$\arg\min_\theta H(p, q_\theta) = \arg\min_\theta \left(-\mathbb{E}_p[\log q_\theta]\right) = \arg\max_\theta \mathbb{E}_p[\log q_\theta] = \hat{\theta}_{\text{MLE}}$$

### 4.2 Cross-Entropy Minimization is MLE

**Claim.** Minimizing the empirical cross-entropy is equivalent to maximum likelihood estimation.

*Proof.* Given data $\{(\mathbf{x}_i, y_i)\}_{i=1}^N$ from the true distribution:

$$\hat{\theta}_{\text{MLE}} = \arg\max_\theta \prod_{i=1}^N q_\theta(y_i | \mathbf{x}_i) = \arg\max_\theta \sum_{i=1}^N \log q_\theta(y_i | \mathbf{x}_i)$$

$$= \arg\min_\theta \left(-\frac{1}{N}\sum_{i=1}^N \log q_\theta(y_i | \mathbf{x}_i)\right) = \arg\min_\theta \hat{H}(\hat{p}, q_\theta) \quad \square$$

### 4.3 Jensen's Inequality

**Theorem (Jensen).** If $g$ is a convex function and $X$ is a random variable, then:

$$g(\mathbb{E}[X]) \le \mathbb{E}[g(X)]$$

If $g$ is strictly convex, equality holds iff $X$ is a constant a.s.

*Proof (discrete case).* By induction on the number of points. Base case ($n=2$): this is the definition of convexity. For the inductive step, let $p_1, \dots, p_n$ be probabilities and $x_1, \dots, x_n$ values. Define $q = p_1 + \cdots + p_{n-1}$ and $\bar{x} = \frac{1}{q}\sum_{i=1}^{n-1} p_i x_i$. Then:

$$\mathbb{E}[g(X)] = \sum_{i=1}^n p_i g(x_i) = q\left(\sum_{i=1}^{n-1}\frac{p_i}{q}g(x_i)\right) + p_n g(x_n)$$

By the inductive hypothesis applied to the first term with weights $p_i/q$:

$$\ge q \cdot g(\bar{x}) + p_n g(x_n) \ge g(q\bar{x} + p_n x_n) = g\!\left(\sum_{i=1}^n p_i x_i\right) = g(\mathbb{E}[X]) \quad \square$$

## 5. PyTorch Implementation

### 5.1 Computing Entropy and KL Divergence

```python
import torch
import torch.nn.functional as F

# --- Entropy of a discrete distribution ---
probs = torch.tensor([0.2, 0.3, 0.5])  # (3,) — categorical distribution
entropy = -(probs * probs.log()).sum()   # scalar — H(p) in nats
print(f"Entropy: {entropy:.4f} nats = {entropy / torch.log(torch.tensor(2.0)):.4f} bits")

# --- Cross-entropy loss in classification ---
# logits: raw model outputs before softmax
logits = torch.randn(4, 10)  # (batch=4, classes=10)
targets = torch.tensor([3, 7, 0, 2])  # (batch=4,) — integer class labels

# PyTorch's cross_entropy expects raw logits (applies log_softmax internally)
loss = F.cross_entropy(logits, targets)  # scalar — average cross-entropy
print(f"Cross-entropy loss: {loss:.4f}")

# Manual computation for verification:
log_probs = F.log_softmax(logits, dim=1)  # (4, 10) — log q(y|x)
manual_loss = -log_probs[range(4), targets].mean()  # scalar
print(f"Manual cross-entropy: {manual_loss:.4f}")

# --- KL divergence between two categorical distributions ---
p = torch.tensor([0.1, 0.4, 0.5])  # (3,)
q = torch.tensor([0.3, 0.3, 0.4])  # (3,)

kl = (p * (p.log() - q.log())).sum()  # scalar — KL(p || q)
print(f"KL(p || q) = {kl:.4f}")

# Using PyTorch's built-in (expects log-probabilities for q)
kl_builtin = F.kl_div(q.log(), p, reduction='sum', log_target=False)
print(f"KL (built-in) = {kl_builtin:.4f}")
```

### 5.2 Gaussian KL Divergence (VAE Style)

```python
def kl_gaussian(mu: torch.Tensor, logvar: torch.Tensor) -> torch.Tensor:
    """
    KL divergence from N(mu, diag(exp(logvar))) to N(0, I).

    Args:
        mu: (batch, d) — mean of approximate posterior
        logvar: (batch, d) — log-variance of approximate posterior

    Returns:
        kl: (batch,) — KL divergence per sample
    """
    # KL = 0.5 * sum_j [sigma_j^2 + mu_j^2 - 1 - log(sigma_j^2)]
    # Since logvar = log(sigma^2):
    kl = 0.5 * (logvar.exp() + mu.pow(2) - 1 - logvar).sum(dim=1)  # (batch,)
    return kl

# Test
batch_size, d = 32, 64
mu = torch.randn(batch_size, d)         # (32, 64)
logvar = torch.randn(batch_size, d)      # (32, 64)
kl_values = kl_gaussian(mu, logvar)       # (32,)
print(f"Mean KL per sample: {kl_values.mean():.4f}")
print(f"KL shape: {kl_values.shape}")
```

### 5.3 Maximum Likelihood Estimation for a Gaussian

```python
import torch
import matplotlib
matplotlib.use('Agg')
import matplotlib.pyplot as plt

def gaussian_mle(data: torch.Tensor) -> tuple:
    """
    MLE for multivariate Gaussian parameters.

    Args:
        data: (N, d) — N samples of d-dimensional data

    Returns:
        mu_hat: (d,) — estimated mean
        sigma_hat: (d, d) — estimated covariance
    """
    N = data.shape[0]
    mu_hat = data.mean(dim=0)                              # (d,)
    centered = data - mu_hat                                # (N, d)
    sigma_hat = (centered.T @ centered) / N                 # (d, d)
    return mu_hat, sigma_hat

# Generate data from a known 2D Gaussian
true_mu = torch.tensor([3.0, -1.0])                        # (2,)
true_sigma = torch.tensor([[2.0, 0.8], [0.8, 1.0]])        # (2, 2)

# Sample using Cholesky
L = torch.linalg.cholesky(true_sigma)                      # (2, 2) lower triangular
N = 1000
z = torch.randn(N, 2)                                      # (1000, 2) — standard normal
data = z @ L.T + true_mu                                    # (1000, 2) — transformed

mu_hat, sigma_hat = gaussian_mle(data)
print(f"True mean: {true_mu}")
print(f"MLE mean:  {mu_hat}")
print(f"\nTrue covariance:\n{true_sigma}")
print(f"MLE covariance:\n{sigma_hat}")
```

### 5.4 Empirical Verification of the Data Processing Inequality

```python
def estimate_mi_ksg(x: torch.Tensor, y: torch.Tensor, k: int = 5) -> float:
    """
    Estimate mutual information using k-nearest neighbor method (KSG estimator).
    Simplified version for demonstration.

    Args:
        x: (N, d1) — samples of X
        y: (N, d2) — samples of Y
        k: number of neighbors

    Returns:
        Estimated I(X; Y) in nats
    """
    from scipy.special import digamma
    from sklearn.neighbors import NearestNeighbors
    import numpy as np

    x_np = x.numpy()
    y_np = y.numpy()
    xy = np.hstack([x_np, y_np])
    N = len(x_np)

    # Find k-th neighbor distance in joint space (Chebyshev metric)
    nn_joint = NearestNeighbors(n_neighbors=k+1, metric='chebyshev').fit(xy)
    distances, _ = nn_joint.kneighbors(xy)
    eps = distances[:, k]  # (N,) — k-th neighbor distance

    # Count neighbors within eps in marginal spaces
    nn_x = NearestNeighbors(metric='chebyshev').fit(x_np)
    nn_y = NearestNeighbors(metric='chebyshev').fit(y_np)

    n_x = np.array([len(nn_x.radius_neighbors([x_np[i]], eps[i], return_distance=False)[0]) - 1
                     for i in range(N)])
    n_y = np.array([len(nn_y.radius_neighbors([y_np[i]], eps[i], return_distance=False)[0]) - 1
                     for i in range(N)])

    mi = digamma(k) + digamma(N) - np.mean(digamma(n_x + 1) + digamma(n_y + 1))
    return max(0, mi)

# Demonstrate data processing inequality: X -> Y -> Z
# X is the raw signal, Y = X + noise1, Z = Y + noise2
N = 5000
X = torch.randn(N, 1) * 2                     # (N, 1)
Y = X + torch.randn(N, 1) * 0.5               # (N, 1) — X -> Y
Z = Y + torch.randn(N, 1) * 0.5               # (N, 1) — Y -> Z

mi_xy = estimate_mi_ksg(X, Y)
mi_xz = estimate_mi_ksg(X, Z)
print(f"I(X; Y) ≈ {mi_xy:.3f} nats")
print(f"I(X; Z) ≈ {mi_xz:.3f} nats")
print(f"I(X; Y) >= I(X; Z)? {mi_xy >= mi_xz - 0.05}")  # allow small estimation error
```

## 6. Connections to Deep Learning

### 6.1 Loss Functions as Negative Log-Likelihoods

| Loss Function | Distribution Assumption | Derivation |
|--------------|------------------------|------------|
| MSE: $\frac{1}{N}\sum_i \Vert y_i - \hat{y}_i\Vert^2$ | $y \sim \mathcal{N}(\hat{y}, I)$ | $-\log p(y\vert\hat{y}) = \frac{1}{2}\Vert y-\hat{y}\Vert^2 + \text{const}$ |
| Cross-entropy: $-\sum_k y_k \log \hat{y}_k$ | $y \sim \text{Cat}(\hat{\mathbf{y}})$ | $-\log p(y\vert\hat{\mathbf{y}}) = -\sum_k y_k \log \hat{y}_k$ |
| Binary CE: $-[y\log\hat{y} + (1-y)\log(1-\hat{y})]$ | $y \sim \text{Ber}(\hat{y})$ | $-\log p(y\vert\hat{y})$ |

### 6.2 Regularization as Priors

- **L2 regularization** ($\lambda\|\theta\|^2$): equivalent to MAP estimation with prior $\theta \sim \mathcal{N}(\mathbf{0}, \frac{1}{2\lambda}I)$.
- **L1 regularization** ($\lambda\|\theta\|_1$): equivalent to MAP with Laplace prior $p(\theta_i) \propto \exp(-\lambda|\theta_i|)$.
- **Dropout**: can be interpreted as approximate variational inference with Bernoulli multiplicative noise (Gal & Ghahramani, 2016).

### 6.3 The Information Bottleneck in Deep Learning

The information bottleneck (Tishby et al., 2000) optimizes:

$$\min_{p(\mathbf{h}|\mathbf{x})} I(\mathbf{x}; \mathbf{h}) - \beta\,I(\mathbf{h}; y)$$

This trades off compression ($I(\mathbf{x}; \mathbf{h})$ small) with prediction ($I(\mathbf{h}; y)$ large). Shwartz-Ziv & Tishby (2017) conjectured that deep networks undergo two phases:
1. **Fitting phase**: $I(\mathbf{h}; y)$ increases rapidly (learning useful features).
2. **Compression phase**: $I(\mathbf{x}; \mathbf{h})$ decreases (discarding irrelevant information).

This remains an active area of research; the compression phase may depend on the activation function and training dynamics.
