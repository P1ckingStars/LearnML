# Capstone Project

**Weight**: 30% of final grade
**Team Size**: 1-3 students
**Duration**: Full semester (4 milestones)

---

## Overview

The capstone is an open-ended project in compilers or programming languages. You will identify a research question or engineering challenge, design a solution, implement it, evaluate it rigorously, and write it up in the style of a conference paper.

## Example Project Topics

### Compiler Engineering

- Build a complete compiler for a non-trivial language targeting LLVM IR or WebAssembly
- Implement a JIT compiler for a dynamic language (e.g., a subset of Python or JavaScript)
- Build an optimizing compiler for a domain-specific language (e.g., linear algebra, image processing)

### Program Analysis

- Implement and evaluate a novel pointer analysis algorithm
- Build a static analysis tool for finding bugs in real-world code
- Implement a symbolic execution engine for a small language

### Programming Languages

- Design and implement a language with algebraic effects and handlers
- Build a gradual type system for an existing dynamically-typed language
- Implement a dependently-typed language with type inference

### Verification

- Verify a compiler pass in Coq or Lean
- Implement translation validation for an LLVM optimization
- Build a verified interpreter

### Applied

- ML-guided compiler optimization (phase ordering, inlining, etc.)
- Compiler support for hardware accelerators (GPU, TPU)
- Incremental compilation system

## Final Report Format

8-12 pages, single-column, in the style of an ACM conference paper:

1. **Abstract** (150 words)
2. **Introduction**: Problem, motivation, contributions
3. **Background**: Related work and necessary theory
4. **Design**: Architecture and key decisions
5. **Implementation**: Technical details
6. **Evaluation**: Benchmarks, correctness testing, comparison to baselines
7. **Discussion**: Limitations, threats to validity
8. **Conclusion**: Summary and future work
9. **References**
