# Notation Reference

## Sets and Relations

| Symbol | Meaning |
|--------|---------|
| $\emptyset$ | Empty set |
| $\Sigma$ | Alphabet (finite set of symbols) |
| $\Sigma^*$ | Kleene closure (all strings over $\Sigma$) |
| $\epsilon$ | Empty string |
| $\subseteq, \subset$ | Subset, proper subset |
| $\cup, \cap$ | Union, intersection |
| $\times$ | Cartesian product |
| $\mathcal{P}(S)$ | Power set of $S$ |
| $R \circ S$ | Composition of relations |
| $R^*$ | Reflexive-transitive closure |
| $R^+$ | Transitive closure |

## Formal Languages

| Symbol | Meaning |
|--------|---------|
| $L(G)$ | Language generated by grammar $G$ |
| $L(M)$ | Language recognized by machine $M$ |
| $A \cdot B$ | Concatenation of languages |
| $A^*$ | Kleene star of language $A$ |
| $\bar{A}$ | Complement of language $A$ |

## Grammars

| Symbol | Meaning |
|--------|---------|
| $G = (N, \Sigma, P, S)$ | Grammar: nonterminals, terminals, productions, start symbol |
| $A \to \alpha$ | Production rule |
| $\Rightarrow$ | Derives in one step |
| $\Rightarrow^*$ | Derives in zero or more steps |
| $\Rightarrow_{lm}$ | Leftmost derivation |
| $\Rightarrow_{rm}$ | Rightmost derivation |
| $\text{FIRST}(\alpha)$ | Set of terminals that can begin strings derived from $\alpha$ |
| $\text{FOLLOW}(A)$ | Set of terminals that can follow $A$ in some derivation |

## Automata

| Symbol | Meaning |
|--------|---------|
| $M = (Q, \Sigma, \delta, q_0, F)$ | Finite automaton |
| $\delta(q, a)$ | Transition function |
| $\hat{\delta}(q, w)$ | Extended transition function |
| $\delta^*(q, w)$ | Same as $\hat{\delta}$ |

## Type Systems

| Symbol | Meaning |
|--------|---------|
| $\Gamma$ | Type environment (context) |
| $\Gamma \vdash e : \tau$ | Expression $e$ has type $\tau$ under context $\Gamma$ |
| $\tau \to \sigma$ | Function type |
| $\forall \alpha. \tau$ | Universal (polymorphic) type |
| $\tau_1 \times \tau_2$ | Product type |
| $\tau_1 + \tau_2$ | Sum type |
| $\tau <: \sigma$ | $\tau$ is a subtype of $\sigma$ |
| $[\tau/\alpha]\sigma$ | Substitution of $\tau$ for $\alpha$ in $\sigma$ |

## Lambda Calculus

| Symbol | Meaning |
|--------|---------|
| $\lambda x. e$ | Lambda abstraction |
| $e_1 \; e_2$ | Application |
| $\to_\beta$ | Beta reduction |
| $\to_\eta$ | Eta reduction |
| $=_\alpha$ | Alpha equivalence |
| $e[v/x]$ | Capture-avoiding substitution of $v$ for $x$ in $e$ |
| $\text{FV}(e)$ | Free variables of $e$ |

## Semantics

| Symbol | Meaning |
|--------|---------|
| $e \Downarrow v$ | Big-step: $e$ evaluates to $v$ |
| $e \to e'$ | Small-step: $e$ steps to $e'$ |
| $e \to^* e'$ | $e$ reduces to $e'$ in zero or more steps |
| $[\![ e ]\!]$ | Denotational semantics of $e$ |
| $\{P\} \; c \; \{Q\}$ | Hoare triple: precondition $P$, command $c$, postcondition $Q$ |
| $\text{wp}(c, Q)$ | Weakest precondition |

## Lattices and Dataflow

| Symbol | Meaning |
|--------|---------|
| $(L, \sqsubseteq)$ | Lattice with partial order |
| $\sqcup$ | Join (least upper bound) |
| $\sqcap$ | Meet (greatest lower bound) |
| $\top$ | Top element |
| $\bot$ | Bottom element |
| $f: L \to L$ | Transfer function |
| $\text{lfp}(f)$ | Least fixed point of $f$ |
| $\text{gfp}(f)$ | Greatest fixed point of $f$ |

## Compiler IR

| Symbol | Meaning |
|--------|---------|
| $\text{dom}(n)$ | Dominators of node $n$ |
| $\text{idom}(n)$ | Immediate dominator of $n$ |
| $\text{DF}(n)$ | Dominance frontier of $n$ |
| $\text{def}(v)$ | Definition site of variable $v$ |
| $\text{use}(v)$ | Use sites of variable $v$ |
| $\phi(v_1, \ldots, v_k)$ | Phi function in SSA |
| $\text{live\_in}(B)$ | Variables live at entry to block $B$ |
| $\text{live\_out}(B)$ | Variables live at exit of block $B$ |
| $\text{gen}(B)$ | Definitions generated in block $B$ |
| $\text{kill}(B)$ | Definitions killed in block $B$ |

## Formal Verification & SMT

| Symbol | Meaning |
|--------|---------|
| $\varphi, \psi$ | Logical formulas |
| $\models$ | Semantic entailment / satisfiability |
| $\sigma \models \varphi$ | Assignment $\sigma$ satisfies formula $\varphi$ |
| $\varphi \models_T \psi$ | $\psi$ follows from $\varphi$ in theory $T$ |
| $(\alpha, \gamma)$ | Galois connection (abstraction, concretization) |
| $f^\sharp$ | Abstract transfer function |
| $\pi$ | Path condition (in symbolic execution) |
