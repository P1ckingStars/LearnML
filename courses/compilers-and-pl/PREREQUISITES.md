# Prerequisites

## Mathematics

### Required

- **Discrete Mathematics**: Sets, relations, functions, partial orders, equivalence relations
- **Logic**: Propositional and first-order logic, proof techniques (direct, contradiction, induction)
- **Proof Techniques**: Mathematical induction, structural induction, well-founded induction
- **Basic Graph Theory**: Directed/undirected graphs, trees, traversals, connectivity

### Helpful (Reviewed in Module 00)

- Formal language theory (regular and context-free languages)
- Lattice theory and fixed-point theorems
- Basic computability (Turing machines, decidability)

## Programming

### Required

- **Proficiency in at least one of**: C, C++, Rust, OCaml, Haskell, or Java
- **Data structures**: Trees, hash tables, graphs, stacks, queues
- **Algorithms**: Graph algorithms (DFS, BFS, topological sort), complexity analysis
- **Systems programming basics**: Memory layout, pointers, stack vs heap

### Helpful

- Experience with functional programming (pattern matching, recursion, higher-order functions)
- Familiarity with x86-64 assembly language
- Experience with build systems and command-line tools

## Computer Science Fundamentals

### Required

- **Computer Architecture**: Basic understanding of CPUs, registers, memory hierarchy, instruction execution
- **Operating Systems**: Process model, virtual memory (conceptual level)

### Helpful

- Previous exposure to a compilers or programming languages course at the undergraduate level
- Familiarity with LLVM or GCC internals

## Recommended Textbooks for Background

- Sipser, *Introduction to the Theory of Computation* -- for automata and computability review
- Cormen et al., *Introduction to Algorithms* -- for algorithms review
- Bryant & O'Hallaron, *Computer Systems: A Programmer's Perspective* -- for systems background

## Self-Assessment

You should be able to:

1. Write a proof by mathematical induction
2. Implement a tree traversal (pre/in/post-order) from scratch
3. Explain the difference between a stack and a heap in memory
4. Write a recursive function and reason about its termination
5. Read and understand basic x86 assembly (mov, add, push, call, ret)
6. Describe what a context-free grammar is
7. Implement a graph algorithm (e.g., topological sort) from scratch

If you can do 5 or more of these confidently, you are ready. If not, review the relevant material and complete HW0 before starting.
