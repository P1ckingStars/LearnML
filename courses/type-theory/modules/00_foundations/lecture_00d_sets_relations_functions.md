## 1. Motivation: Why Sets, Relations, and Functions Matter for Type Theory

Type theory is built on the mathematical infrastructure of sets, relations, and functions. Types are interpreted as sets (in denotational semantics), typing judgments are relations, substitutions are functions, and the semantics of recursive types relies on fixed point theory. Here are some specific connections:

- A *typing context* $\Gamma$ is a partial function from variables to types: $\Gamma : \mathrm{Var} \rightharpoonup \mathrm{Type}$.
- The *typing relation* $\Gamma \vdash e : \tau$ is a ternary relation on contexts, expressions, and types, defined inductively by inference rules.
- *Type equivalence* and *alpha-equivalence* of terms are equivalence relations, and working "up to alpha-equivalence" means working in a quotient set.
- The *subtyping relation* $\tau_1 <: \tau_2$ is a preorder (reflexive and transitive), and often a partial order on equivalence classes of types.
- *Recursive types* $\mu \alpha.\, \tau$ are defined as fixed points of type constructors $F(\alpha) = \tau$, understood through the Knaster--Tarski theorem.
- *Denotational semantics* interprets types as sets (or domains) and terms as elements (or continuous functions), with recursive definitions interpreted via least fixed points of continuous operators.

This lecture develops the relevant mathematical foundations. The treatment is self-contained but focused: we emphasize the concepts and results that appear directly in type theory, and we note the connections as they arise.

## 2. Core Theory

### 2.1 Sets and Set Operations

We work in naive (informal) set theory, which suffices for all purposes in this course. (Formal concerns about Russell's paradox and axiomatic set theory do not arise in the finitary, syntactically-grounded settings of type theory. When we write "the set of all types," we mean the inductively defined set generated by a grammar, not an arbitrary collection.)

**Definition (Set).** A *set* is a collection of distinct objects, called *elements* or *members*. We write $a \in S$ for membership and $a \notin S$ for non-membership.

**Standard notation:**
- $\emptyset$ or $\{\}$: the empty set (contains no elements)
- $\mathbb{N} = \{0, 1, 2, \ldots\}$: natural numbers
- $\mathbb{Z} = \{\ldots, -2, -1, 0, 1, 2, \ldots\}$: integers
- $\{a_1, \ldots, a_n\}$: finite enumeration (listing elements explicitly)
- $\{x \in S : P(x)\}$: set-builder notation (comprehension), the set of elements of $S$ satisfying property $P$

**Definition (Subset).** $A \subseteq B$ (read "$A$ is a subset of $B$") iff for all $x$, $x \in A \implies x \in B$. We write $A \subsetneq B$ for proper containment: $A \subseteq B$ and $A \ne B$.

**Definition (Set equality).** $A = B$ iff $A \subseteq B$ and $B \subseteq A$. This is the *extensionality principle*: two sets are equal iff they have the same elements.

**Definition (Set operations).** Given sets $A, B$ within a universe $U$:

| Operation | Notation | Definition |
|-----------|----------|------------|
| Union | $A \cup B$ | $\{x : x \in A \lor x \in B\}$ |
| Intersection | $A \cap B$ | $\{x : x \in A \land x \in B\}$ |
| Difference | $A \setminus B$ | $\{x : x \in A \land x \notin B\}$ |
| Complement | $\overline{A}$ or $A^c$ | $U \setminus A = \{x \in U : x \notin A\}$ |
| Symmetric difference | $A \triangle B$ | $(A \setminus B) \cup (B \setminus A)$ |

**Generalized operations.** For an indexed family $\{A_i\}_{i \in I}$ of sets:

$$\bigcup_{i \in I} A_i = \{x : \exists i \in I.\, x \in A_i\} \qquad \bigcap_{i \in I} A_i = \{x : \forall i \in I.\, x \in A_i\}$$

**Theorem (Set algebra identities).** For all sets $A, B, C$:

1. *Commutativity:* $A \cup B = B \cup A$ and $A \cap B = B \cap A$.
2. *Associativity:* $(A \cup B) \cup C = A \cup (B \cup C)$ and $(A \cap B) \cap C = A \cap (B \cap C)$.
3. *Distributivity:* $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$ and $A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$.
4. *Identity:* $A \cup \emptyset = A$ and $A \cap U = A$.
5. *Complement:* $A \cup A^c = U$ and $A \cap A^c = \emptyset$.
6. *Idempotence:* $A \cup A = A$ and $A \cap A = A$.
7. *Absorption:* $A \cup (A \cap B) = A$ and $A \cap (A \cup B) = A$.

*Proof of distributivity (3, first identity).* $x \in A \cap (B \cup C) \iff x \in A \land (x \in B \lor x \in C) \iff (x \in A \land x \in B) \lor (x \in A \land x \in C) \iff x \in (A \cap B) \cup (A \cap C)$. The key step uses the distributivity of $\land$ over $\lor$ in logic. $\square$

**Theorem (De Morgan's laws for sets).** For sets $A, B \subseteq U$:

$$(A \cup B)^c = A^c \cap B^c \qquad (A \cap B)^c = A^c \cup B^c$$

*Proof (first law).* $x \in (A \cup B)^c \iff x \notin A \cup B \iff \neg(x \in A \lor x \in B) \iff (x \notin A) \land (x \notin B) \iff x \in A^c \cap B^c$. $\square$

**Remark.** De Morgan's laws for sets mirror De Morgan's laws for propositions (Lecture 00b). Under the propositions-as-types correspondence, $A \cup B$ corresponds to $A + B$ (sum type) and $A \cap B$ corresponds to a form of intersection type. The duality between union and intersection resurfaces as the duality between sum types and product types.

### 2.2 Power Set and Cartesian Product

**Definition (Power set).** The *power set* of $A$ is $\mathcal{P}(A) = \{S : S \subseteq A\}$, the set of all subsets of $A$.

If $|A| = n$ (a finite set with $n$ elements), then $|\mathcal{P}(A)| = 2^n$.

**Proof of $|\mathcal{P}(A)| = 2^n$.** Each subset of $A$ is determined by, for each element $a \in A$, whether $a$ is included or excluded. This is a binary choice for each of $n$ elements, giving $2^n$ subsets. More formally, there is a bijection $\mathcal{P}(A) \cong \{0, 1\}^A$ given by $S \mapsto \chi_S$ (the characteristic function). $\square$

**Connection to type theory.** In set-theoretic semantics, the type $A \to \mathsf{Bool}$ (predicates on $A$) corresponds to $\mathcal{P}(\lbrack\!\lbrack A \rbrack\!\rbrack)$. The power set, ordered by inclusion, is a complete lattice (see below)---a fact we exploit in the Knaster--Tarski theorem.

**Definition (Cartesian product).** The *Cartesian product* of sets $A$ and $B$ is:

$$A \times B = \{(a, b) : a \in A, \; b \in B\}$$

where $(a, b)$ denotes an *ordered pair* (formally definable as $\{\{a\}, \{a, b\}\}$ in ZF set theory, but we treat it as a primitive notion).

If $|A| = m$ and $|B| = n$, then $|A \times B| = mn$.

The $n$-fold product is $A_1 \times \cdots \times A_n = \{(a_1, \ldots, a_n) : a_i \in A_i\}$.

The *indexed product* (dependent product) is:

$$\prod_{i \in I} A_i = \left\{f : I \to \bigcup_{i \in I} A_i \;\middle|\; \forall i \in I.\, f(i) \in A_i\right\}$$

When all $A_i = A$ are the same set, this simplifies to $A^I$, the set of all functions from $I$ to $A$.

**Connection to type theory.** The Cartesian product $A \times B$ is the set-theoretic interpretation of the product type $A \times B$. The indexed product $\prod_{i \in I} A_i$ is the set-theoretic interpretation of the dependent function type $\Pi x{:}I.\, A(x)$.

**Definition (Disjoint union / Coproduct).** The *disjoint union* (or *tagged union*) of sets $A$ and $B$ is:

$$A + B = (\{0\} \times A) \cup (\{1\} \times B) = \{(0, a) : a \in A\} \cup \{(1, b) : b \in B\}$$

The tags $0$ and $1$ ensure that even if $A$ and $B$ overlap (share elements), the two copies are kept separate.

If $|A| = m$ and $|B| = n$, then $|A + B| = m + n$.

The *indexed disjoint union* (dependent sum / sigma type) is:

$$\sum_{i \in I} A_i = \{(i, a) : i \in I, \; a \in A_i\}$$

**Connection to type theory.** The disjoint union $A + B$ is the set-theoretic interpretation of the sum type $A + B$. The injections $\mathsf{inl}(a) = (0, a)$ and $\mathsf{inr}(b) = (1, b)$ are the constructors. The indexed disjoint union is the interpretation of the dependent pair type $\Sigma x{:}I.\, A(x)$.

**Remark (Arithmetic of types).** The notation is suggestive: product types behave like multiplication ($|A \times B| = |A| \cdot |B|$), sum types behave like addition ($|A + B| = |A| + |B|$), function types behave like exponentiation ($|A \to B| = |B|^{|A|}$), the unit type behaves like $1$ ($|\mathsf{Unit}| = 1$), and the void type behaves like $0$ ($|\mathsf{Void}| = 0$). The algebraic laws of arithmetic (distributivity, etc.) correspond to natural isomorphisms between types:

$$A \times (B + C) \cong (A \times B) + (A \times C) \qquad \text{(distributivity)}$$

$$A \to (B \times C) \cong (A \to B) \times (A \to C) \qquad \text{(exponential law)}$$

$$A + B \to C \cong (A \to C) \times (B \to C) \qquad \text{(case analysis)}$$

These isomorphisms are not merely cardinality equalities; they are *natural* bijections definable within the type theory.

### 2.3 Relations

**Definition (Binary relation).** A *binary relation* $R$ from $A$ to $B$ is a subset $R \subseteq A \times B$. We write $aRb$ or $(a, b) \in R$ or $R(a, b)$ interchangeably. When $A = B$, we say $R$ is a relation *on* $A$.

**Definition (Properties of relations on $A$).** A relation $R$ on $A$ is:

| Property | Definition | Formal Statement |
|----------|-----------|------------------|
| Reflexive | Every element is related to itself | $\forall a \in A.\, aRa$ |
| Irreflexive | No element is related to itself | $\forall a \in A.\, \neg(aRa)$ |
| Symmetric | Relatedness is bidirectional | $\forall a, b \in A.\, aRb \implies bRa$ |
| Antisymmetric | Mutual relatedness implies equality | $\forall a, b \in A.\, (aRb \land bRa) \implies a = b$ |
| Transitive | Relatedness composes | $\forall a, b, c \in A.\, (aRb \land bRc) \implies aRc$ |
| Total (connex) | Every pair is comparable | $\forall a, b \in A.\, aRb \lor bRa$ |

**Remark.** Antisymmetry and irreflexivity are *not* the negations of symmetry and reflexivity, respectively. A relation can be both symmetric and antisymmetric (example: the identity relation $\{(a, a) : a \in A\}$ is symmetric because $a = b$ implies $b = a$, and antisymmetric because $aRb \land bRa$ gives $a = a$, which trivially implies $a = b$). A relation can be neither symmetric nor antisymmetric.

**Example (Properties at a glance).** Let us classify several familiar relations:

| Relation | Reflexive | Symmetric | Antisymmetric | Transitive |
|----------|-----------|-----------|---------------|------------|
| $=$ on any set | Yes | Yes | Yes | Yes |
| $\le$ on $\mathbb{N}$ | Yes | No | Yes | Yes |
| $<$ on $\mathbb{N}$ | No | No | Yes | Yes |
| $\subseteq$ on $\mathcal{P}(S)$ | Yes | No | Yes | Yes |
| "has the same parity as" on $\mathbb{Z}$ | Yes | Yes | No | Yes |
| "differs by at most 1" on $\mathbb{Z}$ | Yes | Yes | No | No |
| $\ne$ on any set with $\VertA\Vert \ge 2$ | No | Yes | No | No |

This table illustrates that the properties are logically independent: any combination consistent with the definitions can be realized. In type theory, the relations we encounter most are: equivalence relations (reflexive, symmetric, transitive) for equalities and alpha-equivalence; partial orders (reflexive, antisymmetric, transitive) for subtyping; and preorders (reflexive, transitive) for general notions of "approximation."

**Definition (Image and preimage of a relation).** Given a relation $R \subseteq A \times B$ and a set $X \subseteq A$, the *image* of $X$ under $R$ is $R(X) = \{b \in B : \exists a \in X.\, (a, b) \in R\}$. Given $Y \subseteq B$, the *preimage* of $Y$ under $R$ is $R^{-1}(Y) = \{a \in A : \exists b \in Y.\, (a, b) \in R\}$.

When $R$ is a function $f$, this recovers the standard notions of image and preimage.

**Definition (Composition of relations).** Given $R \subseteq A \times B$ and $S \subseteq B \times C$, their *composition* is:

$$S \circ R = \{(a, c) \in A \times C : \exists b \in B.\, (a, b) \in R \land (b, c) \in S\}$$

Composition is associative: $T \circ (S \circ R) = (T \circ S) \circ R$.

**Definition (Inverse / converse).** The *inverse* of $R \subseteq A \times B$ is:

$$R^{-1} = \{(b, a) : (a, b) \in R\} \subseteq B \times A$$

**Definition (Closure operations).** Given a relation $R$ on $A$:
- The *reflexive closure* $R^=$ is the smallest reflexive relation containing $R$: $R^= = R \cup \{(a, a) : a \in A\}$.
- The *transitive closure* $R^+$ is the smallest transitive relation containing $R$: $R^+ = \bigcup_{n \ge 1} R^n$ where $R^1 = R$ and $R^{n+1} = R \circ R^n$.
- The *reflexive-transitive closure* $R^*$ is the smallest reflexive and transitive relation containing $R$: $R^* = R^= \cup R^+ = \bigcup_{n \ge 0} R^n$ where $R^0 = \{(a, a) : a \in A\}$.

**Connection to type theory.** The multi-step reduction relation $\longrightarrow^*$ is the reflexive-transitive closure of the single-step relation $\longrightarrow$. Type safety says that if $\vdash e : \tau$ and $e \longrightarrow^* e'$, then either $e'$ is a value or $e'$ can take another step. The reflexive-transitive closure can also be defined inductively:

$$\frac{}{e \longrightarrow^* e} \; \text{Refl} \qquad \frac{e \longrightarrow e' \quad e' \longrightarrow^* e''}{e \longrightarrow^* e''} \; \text{Trans}$$

This inductive definition is often more convenient for proofs by rule induction.

#### 2.3.1 Equivalence Relations

**Definition.** An *equivalence relation* on $A$ is a relation that is reflexive, symmetric, and transitive.

**Notation.** Equivalence relations are typically denoted $\sim$, $\equiv$, $\approx$, or $=_\alpha$.

**Definition (Equivalence class).** For an equivalence relation $\sim$ on $A$ and element $a \in A$, the *equivalence class* of $a$ is:

$$[a]_\sim = \{b \in A : a \sim b\}$$

**Definition (Quotient set).** The *quotient* of $A$ by $\sim$ is:

$$A / {\sim} = \{[a]_\sim : a \in A\}$$

It is the set of equivalence classes. There is a natural surjection $\pi : A \to A/{\sim}$ defined by $\pi(a) = [a]_\sim$.

**Theorem (Partition-equivalence correspondence).** Equivalence relations on $A$ are in bijective correspondence with partitions of $A$ (collections of nonempty, pairwise disjoint subsets whose union is $A$).

*Proof.* Given an equivalence relation $\sim$, the equivalence classes $\{[a]_\sim : a \in A\}$ form a partition:
- *Nonempty:* $a \in [a]_\sim$ by reflexivity, so each class is nonempty.
- *Pairwise disjoint:* Suppose $[a]_\sim \cap [b]_\sim \ne \emptyset$. Then there exists $c$ with $a \sim c$ and $b \sim c$. By symmetry and transitivity, $a \sim b$, so $[a]_\sim = [b]_\sim$.
- *Covering:* $\bigcup_{a \in A} [a]_\sim = A$ since $a \in [a]_\sim$ for every $a$.

Conversely, given a partition $\{A_i\}_{i \in I}$, define $a \sim b$ iff $a$ and $b$ belong to the same block $A_i$. Reflexivity: $a$ is in the same block as itself. Symmetry: if $a, b \in A_i$ then $b, a \in A_i$. Transitivity: if $a, b \in A_i$ and $b, c \in A_j$, then $b \in A_i \cap A_j$; since the blocks are disjoint, $A_i = A_j$, so $a, c \in A_i$.

The two constructions are inverse to each other. $\square$

**Example (Alpha-equivalence).** Alpha-equivalence $=_\alpha$ on lambda terms is the equivalence relation generated by renaming bound variables: $\lambda x.\, e =_\alpha \lambda y.\, e[y/x]$ (when $y$ is fresh). The equivalence classes are *alpha-equivalence classes* of terms. In type theory, we typically work with terms "up to alpha-equivalence," meaning we work in the quotient $\Lambda / {=_\alpha}$.

For instance, $\lambda x.\, x =_\alpha \lambda y.\, y =_\alpha \lambda z.\, z$ are all the same equivalence class, representing the identity function.

**Example (Type equivalence).** In type theory, two types $\tau_1$ and $\tau_2$ may be *equivalent* (e.g., $\mathsf{Int} \times \mathsf{Bool}$ and $\mathsf{Bool} \times \mathsf{Int}$ are isomorphic, but not necessarily equivalent in all systems). Definitional equality of types is an equivalence relation that refines syntactic equality.

**Connection to type theory.** Quotient types, available in some type theories (e.g., cubical type theory, Lean's $\mathsf{Quot}$ type), internalize the quotient construction. A quotient type $A / R$ has the same elements as $A$ but identifies elements related by $R$. The elimination principle requires that any function out of $A / R$ must respect $R$ (map $R$-related elements to equal results).

#### 2.3.2 Partial Orders

**Definition.** A *partial order* (or *partially ordered set*, or *poset*) is a pair $(A, \le)$ where $\le$ is reflexive, antisymmetric, and transitive.

**Definition.** A *preorder* is a pair $(A, \le)$ where $\le$ is reflexive and transitive (but not necessarily antisymmetric). Every preorder induces an equivalence relation: $a \equiv b \iff a \le b \land b \le a$. The quotient $A / {\equiv}$ is then a partial order.

**Definition.** A *strict partial order* is a pair $(A, <)$ where $<$ is irreflexive and transitive (hence also antisymmetric).

**Definition.** A *total order* (or *linear order*) is a partial order that is also total: $\forall a, b.\, a \le b \lor b \le a$.

**Examples relevant to type theory:**

| Poset | Elements | Order | Usage |
|-------|----------|-------|-------|
| $(\mathcal{P}(S), \subseteq)$ | Subsets of $S$ | Set inclusion | Lattice theory, inductive definitions |
| $(\mathbb{N}, \le)$ | Natural numbers | Usual ordering | Measures, heights, sizes |
| Types with subtyping | Types | $\tau_1 <: \tau_2$ | Subtyping hierarchy |
| Approximation order | Partial functions $A \rightharpoonup B$ | $f \sqsubseteq g$ iff $g$ extends $f$ | Domain theory |
| Syntax trees | Terms / derivations | Subtree / subderivation | Structural induction |
| $(\{0, 1\}, \le)$ | Booleans | $0 \le 1$ | Monotonicity of type constructors |

**Remark.** The subtyping relation $<:$ is typically a preorder rather than a partial order. We may have $\tau_1 <: \tau_2$ and $\tau_2 <: \tau_1$ with $\tau_1 \ne \tau_2$ syntactically (e.g., $\mathsf{Int} \times \mathsf{Bool}$ and $\mathsf{Int} \times \mathsf{Bool}$ are syntactically equal, but consider a system where record types can be permuted). To get a proper partial order, one quotients by the induced equivalence.

**Definition (Hasse diagram).** A Hasse diagram is a graphical representation of a finite poset. Elements are drawn as nodes, and $a < b$ is represented by an edge from $a$ to $b$ (with $b$ drawn above $a$), omitting edges implied by transitivity.

**Definition (Extremal elements).** In a poset $(A, \le)$:
- $a$ is a *minimal element* if there is no $b < a$.
- $a$ is a *maximal element* if there is no $b > a$.
- $a$ is the *least (minimum) element* (or *bottom*, $\bot$) if $a \le b$ for all $b$.
- $a$ is the *greatest (maximum) element* (or *top*, $\top$) if $b \le a$ for all $b$.

Minimal/maximal elements may not be unique. Least/greatest elements, if they exist, are unique (by antisymmetry).

**Definition (Bounds).** In a poset $(A, \le)$, for $S \subseteq A$:
- An *upper bound* of $S$ is $u \in A$ with $s \le u$ for all $s \in S$.
- A *lower bound* of $S$ is $l \in A$ with $l \le s$ for all $s \in S$.
- The *least upper bound* (lub, join, supremum) of $S$, written $\bigsqcup S$ or $\sup S$, is the smallest upper bound: $u$ is a lub of $S$ if $u$ is an upper bound and $u \le u'$ for every upper bound $u'$.
- The *greatest lower bound* (glb, meet, infimum) of $S$, written $\bigsqcap S$ or $\inf S$, is the largest lower bound: $l$ is a glb of $S$ if $l$ is a lower bound and $l' \le l$ for every lower bound $l'$.

For two elements: $a \sqcup b = \sup\{a, b\}$ (join / binary lub) and $a \sqcap b = \inf\{a, b\}$ (meet / binary glb).

**Proposition.** If a lub (or glb) exists, it is unique.

*Proof.* If $u_1$ and $u_2$ are both lubs of $S$, then $u_1 \le u_2$ (since $u_1$ is a lub and $u_2$ is an upper bound) and $u_2 \le u_1$ (similarly). By antisymmetry, $u_1 = u_2$. $\square$

**Definition (Lattice).** A *lattice* is a poset $(L, \le)$ in which every pair of elements has a join and a meet. Equivalently, binary joins $a \sqcup b$ and binary meets $a \sqcap b$ exist for all $a, b \in L$.

A *bounded lattice* additionally has a top element $\top$ and a bottom element $\bot$.

**Definition (Complete lattice).** A *complete lattice* is a poset in which *every* subset (including infinite and empty subsets) has a join and a meet.

**Proposition.** In a complete lattice:
- $\bigsqcup \emptyset = \bot$ (the bottom element, the least element of $L$).
- $\bigsqcap \emptyset = \top$ (the top element, the greatest element of $L$).

*Proof.* Every element is (vacuously) an upper bound of $\emptyset$. The least upper bound of $\emptyset$ is therefore the least element of $L$, which is $\bot$. Dually for $\bigsqcap \emptyset$. $\square$

**Proposition.** A poset in which every subset has a join is a complete lattice (meets exist automatically, and vice versa).

*Proof.* Given $S \subseteq L$, let $S^u = \{u \in L : \forall s \in S.\, s \le u\}$ be the set of upper bounds. Then $\bigsqcap S = \bigsqcup \{l \in L : \forall s \in S.\, l \le s\} = \bigsqcup (S^l)$ where $S^l$ is the set of lower bounds. But we can also observe: $\bigsqcap S$ (if it exists) equals the join of all lower bounds of $S$. Since all joins exist, this join exists. $\square$

**Example.** $(\mathcal{P}(S), \subseteq)$ is a complete lattice with:
- $\bigsqcup \mathcal{F} = \bigcup \mathcal{F}$ (join = union)
- $\bigsqcap \mathcal{F} = \bigcap \mathcal{F}$ (meet = intersection)
- $\bot = \emptyset$ (bottom = empty set)
- $\top = S$ (top = whole set)

This is the lattice used in the theory of inductive definitions (Lecture 00c) and in the Knaster--Tarski theorem below.

### 2.4 Functions

**Definition (Total function).** A *function* (or *total function*) $f : A \to B$ is a relation $f \subseteq A \times B$ such that for every $a \in A$, there exists exactly one $b \in B$ with $(a, b) \in f$. We write $f(a) = b$ or $a \mapsto b$.

- $A$ is the *domain*, $\mathrm{dom}(f) = A$.
- $B$ is the *codomain*.
- The *image* (or *range*) of $f$ is $\mathrm{im}(f) = \{f(a) : a \in A\} \subseteq B$.
- The *preimage* (or *inverse image*) of a set $S \subseteq B$ is $f^{-1}(S) = \{a \in A : f(a) \in S\}$.

**Definition (Partial function).** A *partial function* $f : A \rightharpoonup B$ is a relation $f \subseteq A \times B$ such that for every $a \in A$, there is *at most one* $b \in B$ with $(a, b) \in f$. We write $f(a) = b$ when defined, $f(a)\!\uparrow$ (or $f(a)$ undefined) when there is no such $b$. The *domain of definition* is $\mathrm{dom}(f) = \{a \in A : f(a) \text{ is defined}\}$.

Every total function is a partial function (with $\mathrm{dom}(f) = A$). A partial function $f : A \rightharpoonup B$ can be viewed as a total function $f : \mathrm{dom}(f) \to B$, or equivalently as a total function $f : A \to B + \{\bot\}$ (using a "bottom" value to represent undefinedness).

**Connection to type theory.** Typing contexts are partial functions. A context $\Gamma : \mathrm{Var} \rightharpoonup \mathrm{Type}$ assigns types to a finite set of variables. The notation $\Gamma, x{:}\tau$ denotes the extension:

$$(\Gamma, x{:}\tau)(y) = \begin{cases} \tau & \text{if } y = x \\ \Gamma(y) & \text{if } y \ne x \end{cases}

$$
This is well-defined as a partial function: $(\Gamma, x{:}\tau)$ is defined on $\mathrm{dom}(\Gamma) \cup \{x\}$. If $x \in \mathrm{dom}(\Gamma)$, the new binding *shadows* the old one (in some conventions) or is disallowed (in others).

#### 2.4.1 Properties of Functions

**Definition.** A function $f : A \to B$ is:

| Property | Definition | Formal Statement |
|----------|-----------|------------------|
| Injective (one-to-one) | Distinct inputs give distinct outputs | $\forall a_1, a_2 \in A.\, f(a_1) = f(a_2) \implies a_1 = a_2$ |
| Surjective (onto) | Every element of $B$ is in the image | $\forall b \in B.\, \exists a \in A.\, f(a) = b$ |
| Bijective | Both injective and surjective | Injective and surjective |

**Equivalent formulation of injectivity:** $a_1 \ne a_2 \implies f(a_1) \ne f(a_2)$ (the contrapositive).

**Theorem (Bijectivity and inverses).** $f : A \to B$ is bijective iff there exists $g : B \to A$ with $g \circ f = \mathrm{id}_A$ and $f \circ g = \mathrm{id}_B$.

*Proof.* ($\Rightarrow$) Define $g(b)$ to be the unique $a \in A$ with $f(a) = b$. Uniqueness follows from injectivity; existence from surjectivity. Then $g(f(a)) = a$ for all $a$ and $f(g(b)) = b$ for all $b$.

($\Leftarrow$) Injectivity: if $f(a_1) = f(a_2)$, then $a_1 = g(f(a_1)) = g(f(a_2)) = a_2$. Surjectivity: for any $b \in B$, we have $b = f(g(b))$ with $g(b) \in A$. $\square$

**Proposition.** If $f : A \to B$ is injective and $A$ is finite, then $|A| \le |B|$. If $f$ is surjective, then $|A| \ge |B|$. If $f$ is bijective, then $|A| = |B|$.

**Theorem (Cantor).** For any set $A$, there is no surjection $f : A \to \mathcal{P}(A)$.

*Proof.* Suppose $f : A \to \mathcal{P}(A)$ is surjective. Define the *diagonal set* $D = \{a \in A : a \notin f(a)\}$. Since $D \subseteq A$ and $D \in \mathcal{P}(A)$, by surjectivity there exists $d \in A$ with $f(d) = D$.

- If $d \in D$: by definition of $D$, $d \notin f(d) = D$. Contradiction.
- If $d \notin D$: by definition of $D$, $d \in f(d) = D$. Contradiction.

In both cases, contradiction. $\square$

**Corollary.** $|A| < |\mathcal{P}(A)|$ for every set $A$. In particular, $|\mathbb{N}| < |\mathcal{P}(\mathbb{N})| = |2^{\mathbb{N}}|$.

**Connection to type theory.** Cantor's theorem has several implications:
1. There is no type $A$ in a consistent type theory with a surjection $A \to (A \to \mathsf{Bool})$. This places fundamental limits on the expressiveness of type systems.
2. The *type of all types* cannot be a type itself without inconsistency (Girard's paradox / Type : Type inconsistency). This is why dependent type theories use universe hierarchies $\mathsf{Type}_0 : \mathsf{Type}_1 : \mathsf{Type}_2 : \cdots$.
3. Not all mathematical functions $\mathbb{N} \to \{0, 1\}$ are computable (there are uncountably many such functions but only countably many programs). This limits what any type system can express.

#### 2.4.2 Function Composition and Identity

**Definition.** Given $f : A \to B$ and $g : B \to C$, their *composition* is $(g \circ f)(a) = g(f(a))$, giving $g \circ f : A \to C$.

Composition is associative: $h \circ (g \circ f) = (h \circ g) \circ f$.

The *identity function* $\mathrm{id}_A : A \to A$ is defined by $\mathrm{id}_A(a) = a$. It is the identity for composition: $f \circ \mathrm{id}_A = f$ and $\mathrm{id}_B \circ f = f$ for any $f : A \to B$.

**Theorem.** The composition of injections is injective. The composition of surjections is surjective. The composition of bijections is bijective.

*Proof (injections).* Let $f : A \to B$ and $g : B \to C$ be injective. If $(g \circ f)(a_1) = (g \circ f)(a_2)$, then $g(f(a_1)) = g(f(a_2))$. By injectivity of $g$, $f(a_1) = f(a_2)$. By injectivity of $f$, $a_1 = a_2$.

*Proof (surjections).* Let $c \in C$. By surjectivity of $g$, there exists $b \in B$ with $g(b) = c$. By surjectivity of $f$, there exists $a \in A$ with $f(a) = b$. Then $(g \circ f)(a) = g(f(a)) = g(b) = c$. $\square$

**Connection to type theory.** Function composition corresponds to composing substitutions and to the transitivity of typing derivations. If $\sigma : \Gamma \to \Delta$ and $\theta : \Delta \to \Xi$ are substitutions (viewed as type-preserving maps), then $\theta \circ \sigma : \Gamma \to \Xi$.

#### 2.4.3 Function Spaces

**Definition (Function space / exponential).** The set of all functions from $A$ to $B$ is:

$$B^A = A \to B = \{f : f \text{ is a function from } A \text{ to } B\}$$

If $|A| = m$ and $|B| = n$ (both finite), then $|B^A| = n^m$.

**Connection to type theory.** The function type $A \to B$ in a type system is interpreted set-theoretically as $\lbrack\!\lbrack B \rbrack\!\rbrack^{\lbrack\!\lbrack A \rbrack\!\rbrack}$, the set of all functions from the denotation of $A$ to the denotation of $B$.

**Theorem (Currying isomorphism).** There is a natural bijection:

$$(A \times B) \to C \;\cong\; A \to (B \to C)$$

*Proof.* Define $\Phi : ((A \times B) \to C) \to (A \to B \to C)$ by $\Phi(f)(a)(b) = f(a, b)$. Define $\Psi : (A \to B \to C) \to ((A \times B) \to C)$ by $\Psi(g)(a, b) = g(a)(b)$. Then:

$\Psi(\Phi(f))(a, b) = \Phi(f)(a)(b) = f(a, b)$, so $\Psi \circ \Phi = \mathrm{id}$.

$\Phi(\Psi(g))(a)(b) = \Psi(g)(a, b) = g(a)(b)$, so $\Phi \circ \Psi = \mathrm{id}$.

Therefore $\Phi$ and $\Psi$ are inverses, establishing the bijection. $\square$

This is the set-theoretic manifestation of currying in functional programming. The function $\Phi$ is curry and $\Psi$ is uncurry.

### 2.5 Fixed Points

Fixed point theory is indispensable for understanding recursive types, recursive definitions, and the semantics of general recursion.

**Definition (Fixed point).** Let $f : A \to A$ be a function (where $A$ might carry additional structure). An element $a \in A$ is a *fixed point* of $f$ if $f(a) = a$.

**Example.** The function $f(x) = x^2$ on $\mathbb{R}$ has fixed points $0$ and $1$. The function $g(x) = x + 1$ has no fixed points in $\mathbb{R}$.

**Definition (Pre-fixed point, post-fixed point).** In a poset $(A, \le)$ with a monotone function $f : A \to A$:
- $a$ is a *pre-fixed point* (or *pre-fixpoint*) if $f(a) \le a$.
- $a$ is a *post-fixed point* (or *post-fixpoint*) if $a \le f(a)$.

A fixed point is both a pre-fixed point and a post-fixed point.

#### 2.5.1 The Knaster--Tarski Theorem

**Definition (Monotone / order-preserving function).** A function $f : L \to L$ on a poset $(L, \le)$ is *monotone* if:

$$a \le b \implies f(a) \le f(b)$$

**Theorem (Knaster--Tarski, 1955).** Let $(L, \le)$ be a complete lattice and $f : L \to L$ be a monotone function. Then:

1. $f$ has a *least fixed point*: $\mu f = \bigsqcap \{x \in L : f(x) \le x\}$ (the meet of all pre-fixed points).
2. $f$ has a *greatest fixed point*: $\nu f = \bigsqcup \{x \in L : x \le f(x)\}$ (the join of all post-fixed points).
3. The set $\mathrm{Fix}(f) = \{x \in L : f(x) = x\}$ of all fixed points forms a complete lattice under the restriction of $\le$.

*Proof of (1).* Let $P = \{x \in L : f(x) \le x\}$ be the set of pre-fixed points. $P$ is nonempty (since $\top \in P$: $f(\top) \le \top$ because $\top$ is the greatest element). Let $p = \bigsqcap P$.

*Step 1: $p$ is a pre-fixed point ($f(p) \le p$).* For any $x \in P$, $p \le x$ (since $p$ is a lower bound of $P$). By monotonicity, $f(p) \le f(x)$. Since $x \in P$, $f(x) \le x$. So $f(p) \le x$. This holds for *all* $x \in P$, so $f(p)$ is a lower bound of $P$. Since $p$ is the *greatest* lower bound, $f(p) \le p$.

*Step 2: $p$ is a post-fixed point ($p \le f(p)$).* From Step 1, $f(p) \le p$. By monotonicity, $f(f(p)) \le f(p)$. So $f(p) \in P$ (it is a pre-fixed point). Since $p = \bigsqcap P$ and $f(p) \in P$, we get $p \le f(p)$.

*Combining:* $p \le f(p)$ and $f(p) \le p$ give $f(p) = p$. So $p$ is a fixed point.

*Least:* If $q$ is any fixed point, then $f(q) = q$, so $f(q) \le q$, so $q \in P$, so $p \le q$. $\square$

*Proof of (2).* Dual to (1). Let $Q = \{x \in L : x \le f(x)\}$ (post-fixed points) and $q = \bigsqcup Q$.

For any $x \in Q$, $x \le q$, so by monotonicity $f(x) \le f(q)$. Since $x \le f(x)$, we get $x \le f(q)$ for all $x \in Q$, so $q \le f(q)$ (as $q$ is the least upper bound and $f(q)$ is an upper bound). By monotonicity, $f(q) \le f(f(q))$, so $f(q) \in Q$, giving $f(q) \le q$. Hence $f(q) = q$. Greatness: if $r$ is a fixed point, then $r \le f(r) = r$, so $r \in Q$, so $r \le q$. $\square$

**Example.** Consider the complete lattice $(\mathcal{P}(\mathbb{N}), \subseteq)$ and the monotone function:

$$F(X) = \{0\} \cup \{n + 2 : n \in X\}$$

The least fixed point is the set of even numbers $E = \{0, 2, 4, 6, \ldots\}$:
- $F(E) = \{0\} \cup \{n + 2 : n \in E\} = \{0\} \cup \{2, 4, 6, \ldots\} = E$. So $E$ is a fixed point.
- Least: any fixed point must contain $0$ (since $0 \in F(X)$ for any $X$) and must be closed under $n \mapsto n + 2$. The smallest such set is $E$.

We can also compute $\mu F$ by iterating from $\bot = \emptyset$:

$$F^0(\emptyset) = \emptyset, \quad F^1(\emptyset) = \{0\}, \quad F^2(\emptyset) = \{0, 2\}, \quad F^3(\emptyset) = \{0, 2, 4\}, \quad \ldots$$

$$\mu F = \bigcup_{n \ge 0} F^n(\emptyset) = E$$

#### 2.5.2 Kleene's Fixed Point Theorem

For *continuous* functions (a stronger condition than monotonicity), the least fixed point can be computed by iteration from the bottom.

**Definition (Chain).** An *$\omega$-chain* in a poset $(L, \le)$ is a sequence $a_0 \le a_1 \le a_2 \le \cdots$.

**Definition ($\omega$-continuous / Scott-continuous).** A function $f : L \to L$ on a complete lattice is *$\omega$-continuous* if for every $\omega$-chain $a_0 \le a_1 \le \cdots$:

$$f\left(\bigsqcup_{n \ge 0} a_n\right) = \bigsqcup_{n \ge 0} f(a_n)$$

Every $\omega$-continuous function is monotone (take constant chains).

**Theorem (Kleene, 1952).** Let $(L, \le)$ be a complete lattice with bottom $\bot$, and let $f : L \to L$ be $\omega$-continuous. Then:

$$\mu f = \bigsqcup_{n \ge 0} f^n(\bot)$$

where $f^0(\bot) = \bot$ and $f^{n+1}(\bot) = f(f^n(\bot))$.

*Proof.* First, we verify that $\bot \le f(\bot) \le f^2(\bot) \le \cdots$ is an $\omega$-chain. Base: $\bot \le f(\bot)$ since $\bot$ is the least element. Induction: $f^n(\bot) \le f^{n+1}(\bot)$ implies $f^{n+1}(\bot) \le f^{n+2}(\bot)$ by monotonicity.

Let $p = \bigsqcup_{n \ge 0} f^n(\bot)$. Then:

$$f(p) = f\left(\bigsqcup_{n \ge 0} f^n(\bot)\right) = \bigsqcup_{n \ge 0} f^{n+1}(\bot) = \bigsqcup_{n \ge 1} f^n(\bot) = \bigsqcup_{n \ge 0} f^n(\bot) = p$$

(The second equality uses $\omega$-continuity. The penultimate equality holds because $f^0(\bot) = \bot \le f(\bot) = f^1(\bot)$, so adding $\bot$ to the chain does not change the supremum.)

So $p$ is a fixed point. Leastness: if $f(q) = q$, then $\bot \le q$; by induction, $f^n(\bot) \le f^n(q) = q$ for all $n$; so $p = \bigsqcup_n f^n(\bot) \le q$. $\square$

**Connection to type theory.** Kleene's theorem gives operational meaning to recursive definitions. The denotation of a recursive function $\mathsf{fix}\;f$ (where $f : (A \to B) \to (A \to B)$) is the least fixed point of $\lbrack\!\lbrack f \rbrack\!\rbrack$, computed as:

$$\lbrack\!\lbrack \mathsf{fix}\;f \rbrack\!\rbrack = \bigsqcup_{n \ge 0} \lbrack\!\lbrack f \rbrack\!\rbrack^n(\bot)$$

Here $\bot$ is the everywhere-undefined partial function (representing divergence), and each application of $\lbrack\!\lbrack f \rbrack\!\rbrack$ extends the function to handle more inputs. The function "unrolls" one level at each iteration.

#### 2.5.3 Recursive Types as Fixed Points

Consider the recursive type $\mathsf{List}(\alpha) = \mu X.\, \mathsf{Unit} + (\alpha \times X)$.

This asks for a type $X$ satisfying $X \cong \mathsf{Unit} + (\alpha \times X)$. The type constructor $F(X) = \mathsf{Unit} + (\alpha \times X)$ is monotone (in an appropriate order on types), and the recursive type $\mu X.\, F(X)$ is its least fixed point.

The constructors arise from the isomorphism:
- $\mathsf{nil} : \mathsf{List}(\alpha)$ (from the $\mathsf{Unit}$ component, via the isomorphism $\mathsf{Unit} + (\alpha \times \mathsf{List}(\alpha)) \cong \mathsf{List}(\alpha)$)
- $\mathsf{cons} : \alpha \times \mathsf{List}(\alpha) \to \mathsf{List}(\alpha)$ (from the $\alpha \times X$ component)

This is an *inductive* type (least fixed point), so it contains only *finite* lists. The greatest fixed point $\nu X.\, \mathsf{Unit} + (\alpha \times X)$ would give a type of *possibly infinite* lists (colists), a *coinductive* type.

**Another example.** Natural numbers: $\mathsf{Nat} = \mu X.\, \mathsf{Unit} + X$. The isomorphism $\mathsf{Unit} + \mathsf{Nat} \cong \mathsf{Nat}$ gives constructors $\mathsf{zero} : \mathsf{Nat}$ and $\mathsf{succ} : \mathsf{Nat} \to \mathsf{Nat}$.

**Another example.** Binary trees: $\mathsf{Tree} = \mu X.\, \mathsf{Unit} + (X \times X)$. The isomorphism gives $\mathsf{leaf} : \mathsf{Tree}$ and $\mathsf{node} : \mathsf{Tree} \times \mathsf{Tree} \to \mathsf{Tree}$.

### 2.6 Typing Contexts as Mathematical Objects

Having developed the necessary tools, we can now be precise about the structure of typing contexts.

**Definition (Typing context).** A *typing context* (or *type environment*) $\Gamma$ is a finite partial function from variables to types:

$$\Gamma : \mathrm{Var} \rightharpoonup \mathrm{Type}$$

with finite domain $\mathrm{dom}(\Gamma) = \{x : \Gamma(x) \text{ is defined}\}$.

We write:
- $\emptyset$ or $\cdot$ for the empty context ($\mathrm{dom}(\emptyset) = \emptyset$).
- $\Gamma, x{:}\tau$ for the context extending $\Gamma$ with the binding $x{:}\tau$.
- $x : \tau \in \Gamma$ or $\Gamma(x) = \tau$ for the lookup.

We can also view a typing context as a finite list (or set) of bindings $x_1{:}\tau_1, \ldots, x_n{:}\tau_n$.

**Convention (Uniqueness of variables).** We typically require $x \notin \mathrm{dom}(\Gamma)$ when forming $\Gamma, x{:}\tau$, ensuring each variable has a unique type in the context. Some formulations allow shadowing, where $\Gamma, x{:}\tau$ overrides any previous binding of $x$.

**Lemma (Context operations).** The following operations are well-defined:

1. *Extension:* $(\Gamma, x{:}\tau)(y) = \tau$ if $y = x$, $\Gamma(y)$ otherwise.
2. *Restriction:* $\Gamma \setminus x$ is $\Gamma$ with $x$ removed from its domain: $(\Gamma \setminus x)(y) = \Gamma(y)$ for $y \ne x$.
3. *Concatenation:* $\Gamma, \Delta$ is defined when $\mathrm{dom}(\Gamma) \cap \mathrm{dom}(\Delta) = \emptyset$, with $(\Gamma, \Delta)(x) = \Delta(x)$ if $x \in \mathrm{dom}(\Delta)$, $\Gamma(x)$ if $x \in \mathrm{dom}(\Gamma)$.

**Lemma (Structural properties of contexts).** The following properties hold for the standard typing rules:

1. *Exchange:* If $\Gamma, x{:}A, y{:}B, \Gamma' \vdash e : C$ and $x \ne y$, then $\Gamma, y{:}B, x{:}A, \Gamma' \vdash e : C$.
2. *Weakening:* If $\Gamma \vdash e : A$ and $x \notin \mathrm{dom}(\Gamma)$, then $\Gamma, x{:}B \vdash e : A$.
3. *Strengthening:* If $\Gamma, x{:}A \vdash e : B$ and $x \notin \mathrm{FV}(e)$, then $\Gamma \vdash e : B$.

These lemmas are proved by rule induction on the typing derivation. Their validity depends on the particular type system:
- In a *linear* type system, weakening fails (you cannot have unused variables).
- In an *ordered* type system, exchange fails (variable order matters).
- In a *relevant* type system, strengthening fails (you cannot discard variables).

### 2.7 Denotational Semantics Preview

Denotational semantics assigns mathematical objects to programs in a *compositional* way: the meaning of a compound expression is determined by the meanings of its parts. The key mathematical structures are exactly those developed in this lecture.

**Definition (Semantic function).** A denotational semantics consists of:
1. For each type $\tau$, a set $\lbrack\!\lbrack \tau \rbrack\!\rbrack$ (the *denotation* of the type).
2. For each well-typed term $\Gamma \vdash e : \tau$, an element $\lbrack\!\lbrack e \rbrack\!\rbrack_\rho \in \lbrack\!\lbrack \tau \rbrack\!\rbrack$, where $\rho$ is an *environment* mapping each variable $x \in \mathrm{dom}(\Gamma)$ to an element of $\lbrack\!\lbrack \Gamma(x) \rbrack\!\rbrack$.

**Sketch for a simple language:**

*Types:*

$$\lbrack\!\lbrack \mathsf{Nat} \rbrack\!\rbrack = \mathbb{N} \qquad \lbrack\!\lbrack \mathsf{Bool} \rbrack\!\rbrack = \{0, 1\}$$

$$\lbrack\!\lbrack A \to B \rbrack\!\rbrack = \lbrack\!\lbrack A \rbrack\!\rbrack \to \lbrack\!\lbrack B \rbrack\!\rbrack \quad \text{(function space)}$$

$$\lbrack\!\lbrack A \times B \rbrack\!\rbrack = \lbrack\!\lbrack A \rbrack\!\rbrack \times \lbrack\!\lbrack B \rbrack\!\rbrack \quad \text{(Cartesian product)}$$

$$\lbrack\!\lbrack A + B \rbrack\!\rbrack = \lbrack\!\lbrack A \rbrack\!\rbrack + \lbrack\!\lbrack B \rbrack\!\rbrack \quad \text{(disjoint union)}$$

*Terms:*

$$\lbrack\!\lbrack x \rbrack\!\rbrack_\rho = \rho(x)$$

$$\lbrack\!\lbrack \lambda x{:}A.\, e \rbrack\!\rbrack_\rho = \text{the function } d \mapsto \lbrack\!\lbrack e \rbrack\!\rbrack_{\rho[x \mapsto d]}$$

$$\lbrack\!\lbrack e_1\;e_2 \rbrack\!\rbrack_\rho = \lbrack\!\lbrack e_1 \rbrack\!\rbrack_\rho(\lbrack\!\lbrack e_2 \rbrack\!\rbrack_\rho) \quad \text{(function application)}$$

$$\lbrack\!\lbrack \langle e_1, e_2 \rangle \rbrack\!\rbrack_\rho = (\lbrack\!\lbrack e_1 \rbrack\!\rbrack_\rho, \lbrack\!\lbrack e_2 \rbrack\!\rbrack_\rho) \quad \text{(pair construction)}$$

$$\lbrack\!\lbrack \mathsf{fix}\;f \rbrack\!\rbrack_\rho = \mu(\lbrack\!\lbrack f \rbrack\!\rbrack_\rho) \quad \text{(least fixed point of } \lbrack\!\lbrack f \rbrack\!\rbrack_\rho \text{)}$$

The last clause uses the Knaster--Tarski / Kleene machinery. For it to be well-defined, we need the function space to carry the structure of a *domain* (a directed-complete partial order with bottom, or *dcpo*), and $\lbrack\!\lbrack f \rbrack\!\rbrack_\rho$ to be *continuous* (preserve directed suprema). This is the subject of *domain theory*, pioneered by Dana Scott in the 1970s.

**Key property: compositionality.** The denotation of $e_1\;e_2$ is determined by the denotations of $e_1$ and $e_2$ separately. This is what makes denotational semantics a useful tool: we can reason about the meaning of a program by reasoning about its parts.

**Key property: adequacy.** A denotational semantics is *adequate* if $\lbrack\!\lbrack e \rbrack\!\rbrack \ne \bot$ implies that $e$ terminates (evaluates to a value). It is *fully abstract* if $\lbrack\!\lbrack e_1 \rbrack\!\rbrack = \lbrack\!\lbrack e_2 \rbrack\!\rbrack$ iff $e_1$ and $e_2$ are observationally equivalent (interchangeable in all program contexts).

## 3. Applications: Cardinality and Decidability

### 3.1 Cardinality Arguments

**Definition.** Two sets $A$ and $B$ have the same *cardinality* ($|A| = |B|$) iff there exists a bijection $f : A \to B$. We write $|A| \le |B|$ iff there exists an injection $f : A \to B$.

**Theorem (Cantor--Schroder--Bernstein).** If $|A| \le |B|$ and $|B| \le |A|$, then $|A| = |B|$.

This theorem says that if there are injections in both directions, there is a bijection. The proof is non-trivial and uses a fixed-point construction.

**Definition (Countability).** A set $A$ is:
- *finite* if $|A| = n$ for some $n \in \mathbb{N}$.
- *countably infinite* if $|A| = |\mathbb{N}|$ (there exists a bijection $A \to \mathbb{N}$).
- *countable* if $|A| \le |\mathbb{N}|$ (finite or countably infinite).
- *uncountable* if $|A| > |\mathbb{N}|$.

**Theorem.** The set of all lambda terms over a countable set of variables is countably infinite.

*Proof sketch.* Lambda terms are finite strings over a countable alphabet (variables, $\lambda$, parentheses, the application juxtaposition). The set of all finite strings over a countable alphabet is countable (by a standard diagonalization/dovetailing argument). Since there are infinitely many lambda terms, the set is countably infinite. $\square$

**Theorem.** $|\mathbb{N} \to \{0, 1\}| = |\mathcal{P}(\mathbb{N})| = 2^{\aleph_0} > \aleph_0$.

**Connection to type theory.** There are uncountably many functions $\mathbb{N} \to \{0, 1\}$, but only countably many lambda terms (and hence countably many computable functions). Therefore, *most* functions on natural numbers are not computable. This is the cardinality basis for the existence of undecidable problems and it fundamentally constrains what type systems (and programming languages) can express about the mathematical universe.

## Summary

- **Sets** with standard operations (union, intersection, complement, power set, Cartesian product, disjoint union) provide the mathematical substrate for types. Product types correspond to $A \times B$, sum types to $A + B$, function types to $B^A$, the unit type to a singleton set, and the void type to $\emptyset$. The arithmetic of types mirrors the arithmetic of natural numbers.

- **Relations** on sets can be reflexive, symmetric, transitive, antisymmetric, etc. Equivalence relations partition sets into classes (relevant for alpha-equivalence, type equivalence, and quotient types). The reflexive-transitive closure of a relation defines multi-step reduction.

- **Partial orders** and **lattices** structure the domains of type theory. A partial order is a reflexive, antisymmetric, transitive relation. A complete lattice is a poset where every subset has a join and a meet. The power set lattice $(\mathcal{P}(S), \subseteq)$ is the prototypical complete lattice.

- **Functions** are special relations satisfying totality and determinacy. Injectivity, surjectivity, and bijectivity are fundamental. Cantor's theorem $|A| < |\mathcal{P}(A)|$ places limits on type-theoretic expressiveness. The currying isomorphism $(A \times B \to C) \cong (A \to B \to C)$ is a foundational fact.

- **Fixed points** of monotone functions on complete lattices are guaranteed to exist by the **Knaster--Tarski theorem**. The least fixed point is $\bigsqcap \{x : f(x) \le x\}$ (meet of pre-fixed points), and the greatest is $\bigsqcup \{x : x \le f(x)\}$ (join of post-fixed points). **Kleene's theorem** computes the least fixed point by iteration from $\bot$ for continuous functions.

- **Recursive types** are modeled as fixed points of type constructors. Inductive types (finite data: lists, trees, natural numbers) are least fixed points. Coinductive types (infinite data: streams, processes) are greatest fixed points.

- **Typing contexts** are partial functions from variables to types. Context operations (extension, restriction, concatenation) support the structural properties (exchange, weakening, strengthening) of type systems.

- **Denotational semantics** interprets types as sets (or domains), terms as elements (or continuous functions), and recursive definitions as least fixed points. Compositionality ensures that meaning is determined structurally.
